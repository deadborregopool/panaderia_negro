========================================================================
REGISTRO OFICIAL DE ESTADO DE TABLAS Y BASE DE DATOS - PANADERÍA CLOUD
========================================================================
Propósito: Fuente de verdad inmutable del estado del esquema, pestañas creadas 
y funciones verificadas para el equipo, GitHub y agentes AI.

------------------------------------------------------------------------
1. TABLAS CREADAS E INICIALIZADAS EN GOOGLE SHEETS
------------------------------------------------------------------------
[x] INSUMO
    - id_insumo (INT, autoincremental)
    - nombre (VARCHAR/Texto)
    - unidad (VARCHAR: kg, g, lt, u)
    - costo_promedio_centavos (INT: céntimos de Soles S/)
    * Nota: Stock NO se almacena en celda; es calculado dinámicamente.

[x] INGRESO_INSUMO
    - id_ingreso (INT, autoincremental)
    - id_insumo (INT, FK -> INSUMO)
    - fecha (DATE: AAAA-MM-DD)
    - cantidad (DECIMAL: 10,3)
    - costo_unitario_centavos (INT: céntimos de Soles S/)

[x] CONSUMO_INSUMO
    - id_consumo (INT, autoincremental)
    - id_produccion (INT, FK -> PRODUCCION)
    - id_insumo (INT, FK -> INSUMO)
    - cantidad (DECIMAL: 10,3)

------------------------------------------------------------------------

------------------------------------------------------------------------
3. FUNCIONES BACKEND IMPLEMENTADAS Y REGISTRADAS
------------------------------------------------------------------------
[x] inicializarBaseDatos()           -> Crea pestañas activas con encabezados en negrita.
[x] crearInsumo(nombre, unidad)      -> Alta de materia prima en INSUMO.
[x] actualizarInsumo(...)            -> Modifica nombre, unidad y costo promedio de un insumo.
[x] registrarIngresoInsumo(...)      -> Carga compra y recalcula costo promedio ponderado.
[x] actualizarIngresoInsumo(...)     -> Modifica compra en historial y recalcula costo promedio ponderado.
[x] recalcularCostoPromedioInsumo()  -> Recalcula costo promedio ponderado sobre compras de un insumo.
[x] obtenerInsumosConStock()        -> Calcula stock en vivo: SUM(Ingresos) - SUM(Consumos).
[x] obtenerHistorialIngresos()       -> Trazabilidad e historial de compras en Soles S/.
